  • Day 18-20Python Analytics Project Discussion, Big Data Architecture, Apache Spark, PySpark Queries, Git & GitHub Version Control & APIs

▼
  • Unit 1-2SQL & RDBMS Concepts, T-SQL Foundation Statements, SELECT, INSERT, SQL Commands (DDL, DML, DCL, DQL), Data Types, Create, Alter, Drop, Delete, Update
